Step 5: The "Undo" Button (TCL)

Database work can be risky. TCL (Transaction Control Language) ensures that your changes are only saved if everything is correct. It is your ultimate safety net.

Transaction Controls

  • COMMIT: This is the "Final Save." Once you commit, your changes are permanent.
  • ROLLBACK: This is the "Emergency Undo." It cancels your changes if something goes wrong.
  • SAVEPOINT: Sets a "Checkpoint" so you can undo back to a specific part of your work.
