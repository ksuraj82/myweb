Step 2: Building the Blueprint (DDL)

Before you can store data, you must build the "structure" or the blueprint of where it will sit. In the professional world, DDL (Data Definition Language) is used to create the tables that hold a company's valuable information.

Note: DDL is like building a house. Once the walls (tables) are built, they stay there until you decide to change the architecture of the building.

Key Features of DDL

  • CREATE: This command builds a brand new table from scratch.
  • ALTER: This allows you to modify an existing table, like adding a new column for "Email Addresses."
  • DROP: This is the "Destroy" button. It removes the table and all its data permanently.

Pro Workflow:

  • Always plan your columns before using CREATE.
  • Use TRUNCATE if you want to wipe the data but keep the table structure.

Common Commands

Follow these examples to build your first data structure:

  1. CREATE TABLE: CREATE TABLE students (id INT, name TEXT);
  2. ALTER TABLE: ALTER TABLE students ADD email TEXT;
  3. DROP TABLE: DROP TABLE students;
