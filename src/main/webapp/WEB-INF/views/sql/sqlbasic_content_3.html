Step 4: Controlling Access (DCL)

In a company, security is everything. DCL (Data Control Language) is used to decide who is allowed to see or edit sensitive information like salaries or passwords.

Security Features

  • GRANT: Gives a specific user permission to perform tasks.
  • REVOKE: Takes that permission away immediately.
