Step 11: Automatic ID Numbers

Every row in a database needs a unique ID number. Instead of you typing 1, 2, 3... manually, the Autoincrement feature does the counting for you.

Why use it?

  • Zero Errors: The computer never forgets the next number.
  • Speed: You only have to worry about the data; the ID handles itself.
