Step 2: Setting up the Ubuntu Server

To start your journey, you need to install the Ubuntu Operating System (OS) inside your VirtualBox. In the professional world, companies use various versions of Linux like RHEL (Red Hat) or Ubuntu. We choose Ubuntu because it is powerful, industry-standard, and completely free for everyone to use.

Note: While Ubuntu is free, the developers accept donations on their website. If you find success in your career after learning these skills, consider a small "thank you" donation to their team. (Note: I am not sponsored by them; I just support their mission!)

Features of the New Ubuntu 26.04 LTS

  • Latest Linux 7.0 Kernel: Better performance for your hardware.
  • Long-Term Support (LTS): You get 5 years of security updates, making it very stable.
  • Enterprise Ready: Includes the latest versions of databases like PostgreSQL 18 and MySQL.

Minimum System Requirements:

  • 1.5 GB of System Memory (RAM).
  • 5 GB of free Hard Drive space.
  • The downloaded "ISO" installer file.

Installation Guide

Follow these steps to bring your virtual server to life:

  1. Download the Image: Download the "Ubuntu Server" file (called an .ISO) from the official site: Download Ubuntu Server.
  2. Load the File: Open VirtualBox, select your machine, go to the Storage settings, and "Insert" the downloaded Ubuntu file into the virtual optical drive.
  3. Run the Setup: Start the virtual machine and follow the on-screen prompts. For a detailed guide on each click, refer to the Official Installation Walkthrough.
  4. Pro Networking Tip: Once installed, go to your VirtualBox Network settings and change "Attached to" to Bridged Adapter.
    Why? This makes your virtual Linux act like a separate, real computer in your house. It allows you to connect to it from your main laptop, which is exactly how developers connect to real database servers in a company.

Once your setup is finished, you have created a professional-grade "Learning Platform." You are now ready to step into the world of IT.
