Step 5: Inspecting File Content

As a developer or engineer, you often need to read log files to find errors. You don't always need to open a big editor; you can "peek" inside from the terminal.

How to View Files

  • cat: Shows the entire contents of a file at once. Best for short files.
  • head: Shows only the first 10 lines (the "top" of the file).
  • tail: Shows the last 10 lines. This is the most used command for checking the latest errors in a log file!
  • less: Opens the file in a way that lets you scroll up and down smoothly.
