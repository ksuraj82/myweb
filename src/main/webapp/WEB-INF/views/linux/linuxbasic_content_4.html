Step 4: Managing Files and Folders

Now that you can move around, you need to learn how to create and organize your work. In a company, you will often create logs or configuration files.

Common Commands

  • mkdir (Make Directory): Creates a brand new folder. (e.g., mkdir my_project).
  • touch: Creates an empty file. (e.g., touch notes.txt).
  • cp (Copy): Makes a duplicate of a file.
  • mv (Move/Rename): Used to move a file to a new folder or change its name.
  • rm (Remove): Deletes a file. Be careful! There is no "Recycle Bin" in the Linux terminal.
