Step 3: Navigating the System

In Windows, you click folders. In Linux, you "move" through them using text. Imagine the Linux file system is a giant building with many rooms (folders). You need to know where you are and how to move to the next room.

Essential Commands

  • pwd (Print Working Directory): This is your "GPS." It tells you exactly which room you are standing in right now.
  • ls (List): This "turns on the lights" in the room so you can see all the files and folders inside.
  • cd (Change Directory): This is your "doorway." Use it to move into another folder (e.g., cd Documents).

Pro Tip: Type cd .. (with a space and two dots) to go back one room toward the exit.
